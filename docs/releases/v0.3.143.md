# FoxDesk 0.3.143

FoxDesk 0.3.143 restores editing of sent comments for authenticated comment
authors. The web interface and backend now apply the same creator-or-admin
permission rule.

## What changed

- Authors can edit their own sent comments.
- Administrators can continue to edit any comment.
- Other users cannot edit comments they do not own.
- The stale agent/admin-only backend precheck has been removed.

This release does not add a database migration or change the ticket editor.

## Upgrade and rollback

1. Back up the FoxDesk database and application files.
2. Install `foxdesk-update-0.3.143.zip` through the self-hosted updater.
3. On a disposable ticket, send a comment, edit it, reload the ticket, and
   confirm that the updated text remains visible.
4. Confirm that another non-admin user cannot edit the comment.
5. If rollback is needed, restore the pre-update application and database
   backups together.
