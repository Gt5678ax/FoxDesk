# FoxDesk 0.3.141

FoxDesk 0.3.141 restores complete ticket editing for administrators and agents
who can access the ticket. The editor now keeps the main ticket fields together
and remains usable on narrow mobile screens.

## What changed

- Edit the subject, description, tags, status, priority, assignee, client, due
  date, and optional custom billable rate from one dialog.
- Validate permissions, staff, client, priority, status, and due-date input on
  the server before saving.
- Save field history and lifecycle transitions atomically.
- Keep Cancel and Save changes reachable in the 390 px mobile layout.
- Record history when an optional field is cleared.

This release does not add a database migration.

## Upgrade and rollback

1. Back up the FoxDesk database and application files.
2. Install `foxdesk-update-0.3.141.zip` through the self-hosted updater.
3. Open a disposable ticket and verify subject, description, workflow, client,
   assignee, and due-date editing on desktop and mobile.
4. If rollback is needed, restore the pre-update application and database
   backups together.

## Verification

- Minimum PHP: 8.1
- Full localization and generated CSS gates pass.
- The isolated ticket-editor E2E test verifies the exact database readback.
