# FoxDesk 0.3.142

FoxDesk 0.3.142 makes the complete ticket editor compatible with strict Content
Security Policy headers. Installations that enforce production CSP can now open
and close the editor without permitting inline JavaScript handlers.

## What changed

- Open the complete ticket editor through an external, versioned JavaScript
  listener instead of an inline event handler.
- Close the editor from its backdrop, Cancel button, or Escape key under the
  same strict CSP.
- Keep all ticket editing introduced in 0.3.141: subject, description, tags,
  status, priority, assignee, client, due date, and optional billable rate.

This release does not add a database migration.

## Upgrade and rollback

1. Back up the FoxDesk database and application files.
2. Install `foxdesk-update-0.3.142.zip` through the self-hosted updater.
3. Open a disposable ticket and verify that Edit opens the dialog, Cancel closes
   it, and saving a harmless test change persists after reload.
4. If rollback is needed, restore the pre-update application and database
   backups together.

## Verification

- Minimum PHP: 8.1
- Ticket editor JS and modal contracts pass.
- The isolated ticket-editor E2E test passes.
- Full localization and generated CSS gates pass.
