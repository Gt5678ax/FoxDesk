# FoxDesk 0.3.140

FoxDesk 0.3.140 makes client companies easier to find and manage. The Clients
page now opens with companies, while portal login accounts remain available in a
separate Contacts tab.

![FoxDesk Clients page with five synthetic organizations](https://raw.githubusercontent.com/lukashanes/foxdesk/main/docs/screenshots/clients-light.png)

## What changed

- Clients opens the company list first.
- Companies and portal contacts have separate, clearly named tabs.
- The page header includes a visible Add company action.
- On narrow screens, the create form appears before long client lists.
- Company wording is clearer in English and Czech, and all 24 locale catalogs remain complete.

This is a focused usability release. It does not add a database migration.

## Upgrade and rollback

1. Back up the FoxDesk database and application files.
2. Install `foxdesk-update-0.3.140.zip` through the self-hosted updater.
3. Verify Clients, Companies, create and edit access, tickets, and reports.
4. If rollback is needed, restore the pre-update application and database backups together.
