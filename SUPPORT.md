# FoxDesk support

## Setup and product questions

Start a [GitHub Discussion](https://github.com/lukashanes/foxdesk/discussions) for
installation, configuration, email, updates, migration, and product questions.
Include your FoxDesk version, PHP version, database, web server, and the step that
is failing.

Choose the category that matches the conversation:

- **Q&A** for setup, configuration, and product questions.
- **Ideas** for a problem or workflow FoxDesk could support better.
- **Show and tell** for useful integrations, configurations, and real workflows.

The self-hosted documentation is available at
[foxdesk.net](https://foxdesk.net/getting-started/introduction/).

## Bugs

Open a [bug report](https://github.com/lukashanes/foxdesk/issues/new/choose) when
you can provide reproducible steps. Remove secrets and customer data from logs and
screenshots.

## Security

Use [private vulnerability reporting](https://github.com/lukashanes/foxdesk/security/advisories/new).
Never post a vulnerability or secret in a public issue or discussion.

## FoxDesk Cloud

This repository tracks the self-hosted edition. Questions about subscriptions,
workspaces, billing, or the hosted service belong to the support channel published
on [foxdesk.net](https://foxdesk.net/contact/).
